Hide removes the Mac desktop by mirroring and can switch the monitor to the other computer over DDC, but the Mac keeps sending video. When the other computer restarts or loses signal, a monitor with Auto Select On scans its inputs and picks the Mac's mirror. Goal: AW3425DW and DELL S2721DGF stay on the other computer until Show, while Dell AW3423DW and Acer K272HUL stay usable.

Try the cheap route first. Both monitors have an OSD Auto Select setting, On by default (AW3425DW guide p.45, S2721DGF guide p.44). With it Off, the monitor should stay on the selected input when that input loses signal. Together with Hide's input switch and Show's DDC return, this may meet the goal without code or private writes. The user changes the OSD setting and runs Hide/Show as normal use; the agent records observations only.

Investigate true disconnect only if that check fails, scoped to the observed failure. It conflicts with the current design: disconnect is single-target, 1–60 s (15 s in the app), refused while displays are hidden, bounded by a deadline helper, and accepts macOS reconnecting a display on wake instead of disconnecting again (wake never disconnects by design). DP-9 qualified one 15-second S2721DGF/M3T101 cycle on Mac17,14, 26A434, USB-C@3/DP: HDMI auto-selection and retained-ID restoration worked, but Mac output needed manual DP selection. Electrical link shutdown, long duration, other-computer reboot, sleep/wake and two targets were not established; AW3425DW disconnect is untested. A 2026-10-14 read-only rehearsal found both targets individually eligible; that is not hardware qualification.

Safety: any private setter call, live restoration, agent-initiated DDC write or disruptive recovery needs fresh scoped approval of exact target, bounded duration, usable survivor, user presence and fallback. Do not relax identity checks, discard unresolved journals or use permanent configuration.

## Acceptance criteria

- [ ] With Auto Select Off on both targets (set by the user) and Hide switching to the other computer's input, record per-target observations for other-computer reboot, other-computer sleep or signal loss, Mac display sleep, Mac sleep/wake and Show input return, including return from a no-signal input. Also hide each target to an unused input, wait for standby, then Show, and record whether it entered standby and returned without the monitor buttons (input for DP-95). Mark each case observed or untested, and note any normal-use downsides of Auto Select Off.
- [ ] If Auto Select Off meets the goal, document the setup and its limits in docs/display-handoff.md and close this task as rejected for true disconnect, citing the observations.
- [ ] If it fails, name the failing case and state whether true disconnect would fix it. Only then publish a feasibility verdict and safety contract covering long sessions, wake re-disconnect, two targets with independent Show, partial failure, helper crash, survivor loss, hotplug and identity changes; the minimum journal, watchdog and lifecycle changes; a per-trial approval-gated hardware plan; and a proceed, defer or reject recommendation compared with a KVM and BetterDisplay's "Disconnect reconnected displays upon wake".

Switch release signing from the self-signed certificate to the Developer ID Application identity, with hardened runtime and secure timestamps, so the output is notarizable.

**Changes**

- `scripts/signing.sh`: sign with `--options runtime --timestamp`. Drop the explicit leaf-SHA-1 `--requirements`; use codesign's default Developer ID designated requirement (`anchor apple generic`, Team ID in `certificate leaf[subject.OU]`), which survives certificate renewal. Keep the SHA-1 pin only to *select* the identity, and keep refusing ad-hoc when signing is required. Commit the expected Team ID and fail if the signed requirement names a different team.
- Ad-hoc local/PR packaging stays as is (no runtime flag needed there unless it is harmless).
- No entitlements file unless a smoke test proves one is needed. Expected: none. The app only `dlopen`s Apple system frameworks (CoreDisplay, IOKit, SkyLight via `RecoveryDisplayBinding`), which library validation allows; it receives Apple Events but sends none; Accessibility needs no entitlement.
- `scripts/import-signing.py`: delete the self-signed trust path (`sudo add-trusted-cert`, `CSSMERR_TP_NOT_TRUSTED` handling). A Developer ID identity must validate as is; if the runner lacks the Developer ID G2 intermediate, import Apple's published intermediate rather than adding trust overrides. Never fall back.
- `scripts/test-signing.py`: update the fake-tool policy checks (runtime + timestamp flags, no leaf pin, team check, nested-before-outer order).
- Docs: replace the self-signed owner setup in docs/development.md with Developer ID setup, acceptance and rotation; update the README install note.

**Out of scope**: notarization (next task). No private setter calls, DDC writes or recovery commands to "test" signing.

## Acceptance criteria

- [ ] `python3 scripts/test-signing.py` passes with runtime/timestamp flags, no leaf pin, team check and nested-first order
- [ ] Local `task build:release` with the Developer ID identity: `codesign --verify --deep --strict` passes; `codesign -d -r-` on app and helper shows anchor apple generic + the committed Team ID and no cdhash; `codesign -dv` shows runtime flag and a timestamp
- [ ] Bundled `dp help` and a read-only probe run under hardened runtime with private symbol lookups still resolving (no writes)
- [ ] workflow_dispatch signing-check imports the Developer ID secret and signs the probe without any trust override
- [ ] Self-signed trust code removed from import-signing.py; docs/development.md and README describe Developer ID setup and rotation

Prove the signed, notarized pipeline end to end with a real prerelease. **Human gates**: pushing the tag needs explicit permission, and installing/opening the app on the desktop needs explicit approval. No blackout, recovery, DDC or private-setter commands are part of this check.

**Steps**

1. With permission, push a prerelease tag (for example `vX.Y.Z-beta.1`) and confirm the release job signs, notarizes, staples and publishes.
2. Download both archives in Safari so they carry quarantine (`gh release download` does not), verify SHA-256, then check `spctl -a -vv -t exec`, `xcrun stapler validate` and `codesign -d -r-` on the app and helper.
3. With desktop approval, install via `scripts/install-release.swift`, open it: no Gatekeeper warning. Grant Accessibility, enable Launch at Login.
4. Publish a second prerelease from a different commit, install over the first, and confirm the Accessibility grant and Launch at Login survive (same Team-ID requirement).
5. Record commits, release URLs and command output as fresh evidence.

## Acceptance criteria

- [ ] Prerelease published by CI (tag push explicitly approved)
- [ ] Browser-downloaded app passes spctl as Notarized Developer ID and stapler validate; opens with no Gatekeeper prompt
- [ ] After installing a second prerelease over the first, Accessibility and Launch at Login still work (desktop interaction approved)
- [ ] Commits, release URLs and command output recorded as fresh evidence

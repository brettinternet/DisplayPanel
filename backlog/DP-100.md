User decision (2026-11-07): Hide style "Turn off" drops the Macs signal to one external display with the private CGSConfigureDisplayEnabled setter, committed for the session, so the monitor enters real standby, and keeps it off until Show, which reconnects it by its saved display ID and restores its mode, origin and main role. Motivation: Dell AW3423DW (QD-OLED, usually main) has no working DDC, so input switching and DDC power are impossible; mirroring Hide shows the mirror and Black out keeps the panel powered. Must coexist with displays hidden by mirroring in the same Hide session. Offline implementation and fake-writer tests only: no private setter call, live restoration or DDC write without fresh scoped approval (DP-101). Supersedes the session-long disconnect candidate in DP-95 for this monitor.

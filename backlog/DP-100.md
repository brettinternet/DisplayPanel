User decision (2026-11-07): Hide style "Turn off" drops the Macs signal to one external display with the private CGSConfigureDisplayEnabled setter, committed for the session, so the monitor enters real standby, and keeps it off until Show, which reconnects it by its saved display ID and restores its mode, origin and main role. Motivation: Dell AW3423DW (QD-OLED, usually main) has no working DDC, so input switching and DDC power are impossible; mirroring Hide shows the mirror and Black out keeps the panel powered. Must coexist with displays hidden by mirroring in the same Hide session. Offline implementation and fake-writer tests only: no private setter call, live restoration or DDC write without fresh scoped approval (DP-101). Supersedes the session-long disconnect candidate in DP-95 for this monitor.

## Acceptance criteria

- [ ] Turn off records a write-ahead journal entry with the saved display ID before the private write, coexists with mirror removals in one Hide session, and refuses built-in, mirrored, hidden or mirror-source targets, no usable physical survivor, non-native drivers and an unrecognized setter.
- [ ] Show reconnects only the saved ID with exact identity checks, waits boundedly for the display, restores its mode, origin and main role (whole baseline when last), and never retries a write; sibling Shows work while a display is turned off.
- [ ] Wake, relaunch, quit and macOS reconnecting the display never turn a display off; the journal stays recoverable and a display macOS reconnected can be put back by Show without a private write.
- [ ] Fake-writer tests cover the journal, topology and app flows; focused suites pass; docs/display-disable.md, display-recovery.md, display-hide-ux.md and CHANGELOG describe Turn off and its limits.

DP-79 and DP-81 added Arrangement protection and Mode protection as disclosure groups at the top of every display page in Displays settings. Arrangement protection is global: it covers each exact set of connected displays plus one preferred main display. It looked per-display and repeated on every page. Mode protection is per display, but it listed every display on every page and split each display's Remember button from its toggle. The user chose this layout: a per-display mode section, and one arrangement status row under the display tiles that opens an Arrangement sheet, like the Arrange button in System Settings.

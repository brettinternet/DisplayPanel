After wake, a hidden monitor can come back off-input with no DP signal, for example the S2721DGF with Monitor Auto Select disabled. The display is then online and inactive but no longer mirrored, and the journal goes to `needsAttention`. Restore can't run from that state because `canAttemptGuardedRecoveryShow` requires the target to match a present display. Today the only way back is switching inputs by hand from the monitor's on-screen menu. Once the mirror returns, a0464c9 clears the failed wake journal back to `mirrored`.

**Decision (2026-11-05): manual guidance first.** When a hidden display needs recovery and is online but inactive and unmirrored, Settings should say it is on another input and should be switched from its own menu. Restore makes no new DDC write. Revisit a guarded DDC input switch, which would reuse the configured return input and `canWaitForInputReturnShow`, only after a scoped live trial shows the monitor accepts DDC while it has no signal.

Pairs with DP-97, which gives these displays a working click action. The guidance text goes where DP-97 routes the click.

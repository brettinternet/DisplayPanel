Provision the Apple credentials release CI needs for Developer ID signing and notarization. **Human-only**: agents must not create, export, read or upload the private key, the `.p12`, its password or the API key. An agent may prepare exact commands and verify secret *names* with `gh secret list`.

**Why**

Self-signed releases still need Privacy & Security → Open Anyway, and their designated requirement pins one certificate leaf. Developer ID plus notarization opens without warnings, and a Team-ID-based requirement survives certificate renewal.

**Owner steps** (Account Holder role is required to create Developer ID certificates)

1. Create a **Developer ID Application** certificate (developer.apple.com → Certificates, or Xcode → Settings → Accounts → Manage Certificates). Keep it in the login keychain for local `task build:release`.
2. Export the identity with its private key as a password-protected `.p12` outside the checkout. Keep an encrypted backup.
3. Create an App Store Connect **Team API key** with the Developer role (Users and Access → Integrations). Record the Key ID and Issuer ID; download the `.p8` once and back it up.
4. Set repository secrets, using the post-DP-88 names (overwrite DP-88's self-signed values if already set):
   - `DISPLAYPANEL_SIGNING_P12_BASE64`, `DISPLAYPANEL_SIGNING_P12_PASSWORD`, `DISPLAYPANEL_SIGNING_IDENTITY` (Developer ID cert SHA-1)
   - `DISPLAYPANEL_NOTARY_KEY_BASE64` (base64 `.p8`), `DISPLAYPANEL_NOTARY_KEY_ID`, `DISPLAYPANEL_NOTARY_ISSUER_ID`
5. Tell the agent the 10-character **Team ID** (not secret; it is committed as the expected signing team).
6. Trash the temporary `.p12`/`.p8` exports after upload and backup. Retain the old self-signed key until the first notarized release ships, then it may be deleted.

Commands for upload follow the pattern in docs/development.md (pipe base64 into `gh secret set`; let `gh` prompt for passwords).

## Acceptance criteria

- [ ] Developer ID Application identity is in the owner login keychain and `security find-identity -v -p codesigning` lists it as valid
- [ ] `gh secret list` shows all six DISPLAYPANEL_SIGNING_* / DISPLAYPANEL_NOTARY_* secrets (names only recorded)
- [ ] Team ID recorded in this task
- [ ] Encrypted backups of the .p12 and .p8 exist in owner storage; temporary exports trashed
